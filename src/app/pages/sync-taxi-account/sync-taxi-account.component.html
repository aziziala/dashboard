Synchronise le compte taxi pour un numéro : le backend vérifie la présence du taxi côté client API (gateway /taxi-client/api) et du compte côté JWT (service sync via /api/sync-taxi-account). Tout passe par le même origine que le dashboard (proxy / nginx) — pas d’URL directe vers les ports internes, donc pas de CORS navigateur.

Si le serveur demande des données d’immatriculation, le formulaire ci-dessous s’affiche automatiquement après la première tentative.
